# Security policy

This is non-production demonstrator software. Supported versions, if any, are
identified in published GitHub releases; no support-time or response-time SLA
is promised.

## Reporting a vulnerability

Report suspected vulnerabilities through the repository's **Security and
quality → Advisories → Report a vulnerability** private channel. Do not include
secrets, exploit details, or personal data in public issues.

Private vulnerability reporting is enabled for this repository. Reports are
monitored and triaged by authorized maintainers from the DOTSOFT R&D DARIUS
team through GitHub Security Advisories.

Reports should include the affected revision, reproduction steps, impact, and
any suggested mitigation. Maintainers will acknowledge and triage reports
before deciding disclosure timing; no response-time SLA is claimed.
