# Generated demonstration evidence

- `events.jsonl`: deterministic hash-chained events from the three-round offline reproduction.
- `reproduction_summary.json`: synthetic city metrics and artifact hashes from that run.
- `flower_network_result.json`: final summary from the locally verified two-round, three-client Flower transport smoke test.

This evidence uses only included synthetic datasets and models. It is demonstrator output, not an internal evidence package, signed audit record, municipal validation, or production result. Regeneration overwrites the offline files; a networked Flower run overwrites the network result.
